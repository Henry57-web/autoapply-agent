# AutoApply Agent

An agent project for automating job discovery, resume customization, and application workflows.

## Vision

AutoApply Agent helps with:

- finding matching job posts
- tailoring resumes and cover letters
- tracking application progress
- adding review checkpoints before submission

## Next Steps

1. Define target job boards and data sources.
2. Design the agent workflow and approval gates.
3. Build integrations for resume generation and form filling.
